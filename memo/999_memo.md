## 事前準備(1) ライブラリについて

Pythonでは，高度な計算を簡単なコマンドで実行するための「ライブラリ」というものが用意されています．
前回のchapterで, プログラムの冒頭に書いた ``import numpy as np`` の "numpy" がそれにあたるものですね．
numpy は高度な数値計算を可能にする Python の基本的で強力なライブラリの一つです．

- 注）この辺りがよくわかっていなければ「python ライブラリ とは」とかで調べてください．

機械学習でよく使われる計算をまとめたライブラリも当然存在します．
"scikit-learn" と呼ばれるライブラリがそれです．

ところでライブラリは最初にインストールをしていないと使えません．

- 注）ライブラリをインストールするには？
  - ライブラリをインストールする代表的な方法は "conda" と "pip" です．
    - 違いについては自分で調べてください
  - 今回は，Anacondaによって環境を管理しているので，condaを利用する方法を用いています．
    - ここでは CLI でインストールする方法を書きますが，Anaconda Navigatorを使ってGUIベースでインストールする方法もあります．

ターミナル（Anaconda promptなど？）を開き．．．
```
# まず，自分が使っているanacondaの仮想環境("hoge"という名前であるとする)に入る
$ conda activate hoge
# すると（多くの場合）仮想環境の名前がプロンプトに表示されるようになる（最初から表示されていれば上の操作は不要）
(hoge)$ 
# scikit-learn のインストール
(hoge)$ conda install scikit-learn
```

- ターミナルの種類と比較
  - Mac
    - ターミナルapp（純正）
  - Windows
    - git bash
    - MobaXterm
    - Anaconda prompt
    - コマンドプロンプト
    - Powershell
    - Windows terminal（最近ようやく出てきたらしい）
    - WSL（ちょっと違う気がするけど）
    - 他，色々...「windows ターミナル」とか調べればいっぱい出てきます．
